# Creating an intake request (standalone NFA)

Status: current · Last reviewed: 2026-09 · Audience: buyers and requesters · Source file: Complete Guide to Creating an Intake Request.pdf · Ingested: 2026-09-12

A step-by-step guide for creating an Intake Request for Standalone NFA on the portal. It covers selecting the required plant, location, vendors, and approval workflow, along with the complete submission process for effective request creation and processing.

## Intake Request Initiation

1. Navigate to your portal and click on Intake.
2. Click on Create Request.

## General Information Setup

3. Enter the Title of the Intake Request.
4. Select 'Standalone NFA' as the Request Condition.
5. Click 'Next' to proceed to submitting further details.

## Proposal and Vendor Details

6. Enter the required details here.
7. Enter the Priority here through the dropdown section.
8. Set the Category through dropdown.
9. Select the Location.
10. Set the Department/Procurement Function through the dropdown and then enter the Savings Percent/value as well.
11. Upload the 'Final QCS / Approval Note' file.
12. Select the Recommended Vendor.
13. Enter Basic Total.
14. Enter Payment Terms as per your requirement.
15. Enter the Remarks From Originator field.

## Approval Submission

16. Click 'Next' to view the Approval Flow.
17. Select the required approval workflows and click Send.
18. Click 'Send Request' to submit for approval.

## Post-Submission Management

19. If you want to communicate with the user, you may use the comment section.
20. You may enter comment/remarks to communicate with the users.
21. Switch to the 'Request Details' tab if you want to view the details which you have filled previously.
22. Click "Options" where you can select the option to Withdraw, Recreate or view Audit Logs.
