# Creating and managing a PR-based event

Status: current · Last reviewed: 2026-09 · Audience: buyers · Source file: Creating and Managing a PR-Based Event.pdf · Ingested: 2026-09-12

A step-by-step guide to creating a PR-based event, understanding the available configuration options, extending or ending the event after publishing, sending reminders, changing the event owner, and withdrawing the event when required.

## Create a project from a PR item

1. Navigate to your portal and click on Purchase Requisitions.
2. Select the PR item for the creating an event.
3. Click "Start New Project"
4. Click here to edit the quantity if needed.
5. Click "Create Project"
6. The stages will be reflected so you can select the same as per your requirement and click on Create Project again.
7. Once you click on create project, it will re-direct you to the next page where details of the stages would be visible and you may select the template here as per your requirement.
8. Click the project title to enter the title as per your requirement.

## Technical stage: evaluator and schedule

9. Once the title is entered, click "Technical Stage"
10. The evaluator will be assigned by default based on the PR creator for the respective PR item.
11. If no evaluator is assigned, click on the evaluator field. The dropdown will show users mapped to the same Fund Centre/WBS element as the PR item. You can select the required evaluator from the list.
12. You may set the schedule of the technical stage by clicking here.
13. You can make the changes here for the order duration of the technical stage as required.
14. Click "Save Schedule"

## RFQ stage: vendors, schedule and attachments

15. Click "RFQ"
16. Click the vendor search field to add the participants here.
17. You may either search the vendors through their vendor company name or their vendor code, the list of vendor will be visible in the dropdown and you may select the vendors through the same.
18. You may set the schedule of the RFQ by clicking here.
19. You can make the changes here for the order duration of the RFQ as required.
20. Click "Save Schedule"
21. Open the attachment upload dialog to add the attachments if required.
22. Add attachments and click "Save"
23. Open the Items icon to view the line items included in the event.
24. Click Save as draft if you don't want to publish the event at the moment and make some changes.

## Publish: open tender or invited vendors only

25. Now if all the details have been added, you may click "Publish"
26. Here, you can choose whether to publish the event as an Open Tender. Open Tender: All vendors can view and participate in the event by self-registering, even if they were not added as participants. Not Open Tender: Only the vendors added as participants can access and participate in the event.
27. Click "Publish"
28. Once you publish the event, the RFX number will be generated and all the details would be visible as below.

## Extend or end a stage after publishing

29. Open the Technical Stage to view the setting available, you may extend/end the submission time of the particular stage, view the order activity logs, edit the evaluation time as well.
30. Same goes for the RFQ stage as well, you may extend/end the submission time of the particular stage, view the order activity logs, edit the evaluation time as well.
31. You may extend the submission time of the particular stage, select the required time and click ok.
32. Same for ending the submission time.
33. Mention the reason here for ending the submission time of the particular stage.
34. Click "Confirm"

## Follow-up actions: reminders

35. Now you have other follow up actions too, once you click on ":" on the right top corner, you have the option to send reminders to vendors or evaluators, change the owner of the event whenever required and even withdraw the whole project/event.
36. To send reminders, click here.
37. Select the user and click "Send Reminder"
38. Same goes for the vendors too, select the vendor and click "Send Reminder"

## Change the event owner

39. Now if you wish to change the owner of the event, click "Change Owner"
40. The list of buyers who belongs to the same team, their names would be visible and you may select via the same.
41. Click "Change owner"

## Withdraw the project

42. Now, if you wish to change the withdraw the whole project/event, click "Withdraw Project"
43. Mention the reason for withdrawing the project/event.
44. Click "Yes, Withdraw Project". The whole project/event will be withdrawn and move to the history section.
