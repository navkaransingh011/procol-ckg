# MMG: how to create a forward auction

Status: current · Last reviewed: 2026-09 · Audience: buyers (MMG) · Source file: MMG- FORWARD AUCTION.pptx · Ingested: 2026-09-12

Step-by-step slides for publishing a forward (sell-side) auction on app.procol.in.

## Create the event

1. Go to the Events tab.
2. Click "+ Create Event" and select Single Stage.
3. A new window opens.

## Choose the event type and configuration

4. Click "Event type".
5. Select Auction from the types shown.
6. Select the required configurations for your requirement.

## Template and floor price

7. Select the "Sell Template" from the dropdown.
8. Click "Add Columns" and select Floor Price from the Creator option; the Floor Price column is added to the template.

## Products, terms and vendors

9. Add the product in the Product column.
10. Fill in the details in the template.
11. Add Terms & Conditions and vendors accordingly.

## Schedule and publish

12. Schedule the event as required and click "Publish Event".
13. The forward auction is published.
