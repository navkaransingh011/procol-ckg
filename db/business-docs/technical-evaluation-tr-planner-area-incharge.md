# Technical evaluation: submitting the TR as planner and area incharge

Status: current · Last reviewed: 2026-09 · Audience: buyers, planners and area incharges (AMNS) · Source file: HowtosubmitTRfortechnicalstageasplannerandareaincharges.pdf · Ingested: 2026-09-12

Learn how to efficiently manage vendor RFQ processes and submit technical evaluations within the Procol Console platform. This guide provides a step-by-step walkthrough for adding vendors, publishing requests, and navigating the re-evaluation workflow.

## Assign the planner while creating the event

1. While creating an event the buyer can select the planner for evaluation
2. When you click on edit option a dropdown will appear in which all the planners that are mapped to the WBS or Fund center of the particular PR and from which you can choose the planner accordingly.
3. Do the same for second line item.
4. Click "Publish"

## Planner evaluates after the event closes

5. After bids have been received and the event is over, the buyer has to send the TR for evaluation. Unless the buyer sends the event for evaluation it will not be visible to the planner.
6. After evaluation is requested the planner will be able to add evaluation.
7. Select the score accordingly.
8. You can enter the remarks for selecting the score.
9. You can add evaluation for all the vendors and all the line items.

## Area incharge as a second evaluator

10. The planner can select area incharge as an evaluator so that they can further evaluate the TR. The area incharge should also be mapped to the relevant fund center or WBS. Only then their name will be visible in the dropdown.
11. After that the area incharge will also be able to edit the TR by clicking on edit option.
12. Click "Send" to further send it to the planner.

## Submit the TR (technical recommendation) for approval

13. The planner will be able to submit the TR further for approvals.
14. They can select the required workflow that is configured.
15. Click "Submit"

## Re-evaluation

16. If planner is not satisfied with the scored they can request re evaluation. Click "Request re-evaluation"
17. After the TR is sent for re evaluation the area incharge will be able to edit the scored accordingly and send it again.
18. Click "Send"
19. The planner then can further submit the TR accordingly for further apporvals.
